# Test scans

Put scanned PDFs of the **test packet** here (see `test-sheets/test-packet.pdf`).
The automated tests will use them to check that the scan reader keeps working.

How to upload (on github.com):
1. Open this folder (`test-scans`) in the repository, on the **main** branch.
2. Click **Add file → Upload files**.
3. Drag the PDF in, then click **Commit changes**.

Name the files so we can tell them apart, e.g. `copier-gray-300dpi.pdf`, `copier-bw.pdf`.
