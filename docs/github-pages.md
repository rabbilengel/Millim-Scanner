# Turning on GitHub Pages

GitHub Pages turns the repository into a website, so you can open the app from any computer with just a link.

## 1. Make the repository public (needed on a free GitHub account)

1. On github.com, open the repository and click **Settings** (top right of the repository page).
2. Scroll to the very bottom, to **Danger Zone**.
3. Click **Change visibility** → **Change to public**, and confirm (GitHub may ask you to type the repository name).

Remember: once it's public, anyone on the internet can see the files, including `data/roster.csv`.

## 2. Turn on Pages

1. In **Settings**, click **Pages** in the left-hand menu.
2. Under **Build and deployment** → **Source**, choose **Deploy from a branch**.
3. Under **Branch**, choose **main** and **/ (root)**, then click **Save**.
4. Wait 1–2 minutes and refresh the page. A box appears at the top: "Your site is live at …".

Your app's address will be:

**https://rabbilengel.github.io/Millim-Scanner/**

Bookmark it. Every time you merge changes into main, the site updates itself within a couple of minutes.
If you don't see a change, press **Ctrl+F5** to reload without the browser's saved copy.
